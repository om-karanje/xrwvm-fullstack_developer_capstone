# Best Cars Dealership Application

## Repository Name

xrwvm-fullstack_developer_capstone

## Project Name

Best Cars Dealership Full Stack Application

## Project Description

This project is part of the IBM Full Stack Application Development Capstone Project. It is a full stack car dealership platform with a Django web application, static HTML pages, React frontend components, an Express and MongoDB dealer service, a sentiment analyzer microservice, and deployment configuration.

## Technologies Used

- Python, Django
- HTML, CSS, JavaScript, React
- Node.js, Express, MongoDB
- Docker, Kubernetes, GitHub Actions
